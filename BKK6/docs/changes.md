# V6 ต่างจาก V5 อย่างไร

ผลคำนวณหลักยังใช้ไฟล์ `(5).xlsx` เดิมและสูตรที่ตรวจแล้ว จึงไม่ควรเปลี่ยนตัวเลขเพียงเพราะเปลี่ยนรูปแบบรายงาน สิ่งที่เปลี่ยนคือการอธิบายและการตรวจประกอบ:

- ใช้ README เป็นงานหลักสำหรับ GitHub ไม่มี PDF หรือ PowerPoint ในชุดส่งใหม่นี้
- กราฟ 14 ภาพใช้ป้ายภาษาไทยและคำเต็ม อธิบายแกน สี หน่วย วิธีคำนวณ ข้อค้นพบ ข้อจำกัด บทพูด และภาพที่ควรใช้หน้าชั้นแยกทุกภาพ
- กราฟวันที่ใช้วันที่จริงบนแกนและมีตารางวันที่เต็ม กรณีศึกษาสองช่องใช้สเกลเดียวกัน
- เพิ่มตารางคำถาม–สมมติฐาน–หลักฐาน–ข้อสรุป และลำดับพูด 3 ข้อค้นพบหลัก
- ตรวจต่อว่า 168 แถวที่นิยาม Lockdown ไม่ตรงกัน อยู่ในชุดจับคู่สามช่วง 29 แถว และในชุดจับคู่ Lockdown 11 แถว ไม่เปลี่ยนค่าป้ายในข้อมูลดิบ
- ตรวจตัวเลขหกแถวกับข้อความรายงานต้นทาง พร้อมระบุขอบเขตที่ยังไม่ตรวจภาพ/ชื่อถนน
- เพิ่มหลักฐานบัญชีข้อมูลภาครัฐที่แสดงว่าไม่ได้ระบุ license และแยกสถานะนี้ออกจากการเข้าถึงไฟล์ได้
- ใส่สมาชิก 3 คนและ repository ตามที่แจ้ง ไม่แต่งหน้าที่ของสมาชิก
- Notebook ฝังโมดูลและฟอนต์ไว้เพื่อรันโดยไม่ต้องหา src เอง ใช้ผลเดิมเฉพาะเมื่อ SHA256 ของไฟล์ตรงกัน ถ้าไฟล์เปลี่ยนจะเข้าสู่ขั้นตรวจและคำนวณใหม่

V5 และเวอร์ชันก่อนหน้าเก็บไว้แยก ไม่ได้แก้โค้ดหรือ README เดิม งาน V6 ยังมีรายการที่ต้องยืนยันจากภายนอกตามที่ระบุใน README ไม่ใช่การรับรองว่าแก้ปัญหาต้นทางทุกแถวหรือผ่านข้อกำหนดสิทธิใช้ข้อมูลแล้ว
